# 숏 레이더 — NASDAQ 초소형·소형주 급등 잠재력 / 숏(공매도) 분석 대시보드 (개인용)

> ⚠️ **투자 권유 아님.** 이 앱은 개인 학습·분석용 도구입니다. 화면의 숏 잔고 분포·진입 구간·확률·손익비는 **무료 데이터로 만든 추정치**이며 실제와 다를 수 있습니다. 무료 시세는 **지연될 수 있습니다**. 모든 매매 판단과 책임은 본인에게 있습니다.

Python + Streamlit + 커스텀 HTML/CSS(다크 카드). 데이터는 SQLite(`data/shortdash.sqlite`)에 캐시·누적됩니다. 폰 화면 폭 기준으로 디자인했습니다.

## 1. 빠른 시작 — 집 PC에서 실행 (한 번 클릭)

준비물: **Python 3.10 이상** (https://www.python.org/downloads/ — Windows 설치 시 **"Add python.exe to PATH" 체크**). 계정 만들 필요 없음.

1. `short-dashboard.zip` 압축을 원하는 폴더에 풉니다 (예: `C:\short-dashboard`, 경로에 한글이 없으면 더 안전).
2. 실행
   - **Windows**: `run.bat` 더블클릭
   - **Mac**: `run.command` 더블클릭 (처음엔 "확인되지 않은 개발자" 경고 → 파일 우클릭 → **열기** → 열기). 안 되면 터미널에서 `chmod +x run.command` 후 다시 실행
3. 첫 실행은 가상환경(.venv) 생성 + 패키지 설치로 **3~5분**, 그다음 앱이 **초기 데이터베이스를 자동으로 만듭니다** (화면에 "처음 실행: 초기 데이터베이스를 만드는 중" 진행 표시, 보통 3~10분, 한 번만). 두 번째부터는 수 초 안에 열립니다.
4. 브라우저에서 `http://localhost:8501` 이 열립니다. 창(검은 콘솔/터미널)을 닫으면 앱이 꺼집니다.

수동 실행(같은 내용):
```bash
python -m venv .venv
# Windows: .venv\Scripts\activate    Mac/Linux: source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py --server.address 0.0.0.0 --server.port 8501
```

### 📱 폰에서 보기 (같은 와이파이)
1. PC와 폰을 **같은 와이파이**에 연결
2. `run.bat` / `run.command` 창에 표시되는 **"폰에서 접속: http://192.168.x.x:8501"** 주소를 폰 브라우저에 입력
   - 주소가 안 보이면 PC IP 확인: Windows `ipconfig` → "IPv4 주소" / Mac `시스템 설정 → Wi-Fi → 세부사항 → IP 주소`
3. 안 열리면 방화벽: Windows 처음 실행 때 뜨는 "Windows 보안 경고"에서 **개인 네트워크 허용**(못 봤다면 `제어판 → Windows Defender 방화벽 → 앱 허용`에서 python 허용). Mac은 "들어오는 연결 허용" 선택
4. **홈 화면에 추가**: iPhone Safari → 공유(□↑) → "홈 화면에 추가" / Android Chrome → ⋮ → "홈 화면에 추가". 아이콘 이름은 `숏 레이더`
   - http(내부 IP) 주소는 브라우저에 따라 전체 화면 앱 대신 일반 바로가기로 추가될 수 있습니다 (기능은 같음)
   - PC가 꺼져 있거나 절전이면 폰에서도 안 열립니다. 집 밖(LTE)에서는 접속되지 않습니다 → 밖에서도 쓰려면 아래 2번(선택)

### 매일 업데이트 (선택, 히스토리 누적)
앱을 열면 필요한 데이터는 자동으로 받지만, 매일 아침 미리 갱신해 두면 빠릅니다.

- Mac: `crontab -e` → `0 7 * * 2-6 cd /경로/short-dashboard && .venv/bin/python scripts/update_daily.py`

### 📲 급등 신호 폰 알림 (ntfy · 무료, 계정 불필요)
1. 폰에 **ntfy** 앱 설치 (Play 스토어 / App Store)
2. 대시보드 **관리 탭 → 📲 폰 알림 (급등 신호) · 토스 링크** 에 보이는 **주제 이름**(처음 실행 때 무작위로 자동 생성, 예 `shortradar-xxxxxxxxxxxxxxxx`)을 ntfy 앱에서 **Subscribe** → 그대로 입력
3. 같은 화면의 **테스트 알림 보내기** → 폰에 알림이 오면 성공 (결과에 `ntfy HTTP 200` 표시)
4. 알림을 실제로 보내는 건 **알림 스캐너**입니다: PC면 `run_alerts.bat`(Windows) / `run_alerts.command`(Mac) 를 장 시간 동안 켜 두면 몇 분마다 스캔합니다. PC를 꺼도 받으려면 → 2번 클라우드.
- 알림 종류: 상위 확률 신호 · 커버 압력 · 재점화 레벨 근접/돌파 · 거래량 폭증(RVOL) · 프리마켓 갭. 같은 종목·같은 종류는 **재알림 간격(기본 120분)** 동안 다시 안 보냄. **방해 금지** 시간(KST)·최소 레벨 설정 가능.
- 최근 30일 424B 증자·역분할·희석 위험 종목은 **⚠ 표시하고 보내기** 또는 **보내지 않기(기록만)** 중 선택.
- 알림 내용(한국어): 종목·신호 종류·보정 확률·진입 구간·손절·목표 + **토스에서 열기** 버튼.
- 보낸/막힌 알림은 **오늘 탭의 알림 기록**에 남고, 10거래일 뒤 자동 채점(성공/실패) → **관리·타임머신 탭의 "실전 알림 성적"** (표본 30건 미만이면 경고 표시).
- **텔레그램(선택)**: 봇 토큰/채팅 ID 를 **환경변수로만** 넣습니다 (`run.bat`·`run_alerts.bat` 맨 위에 `set TELEGRAM_BOT_TOKEN=xxxx` / `set TELEGRAM_CHAT_ID=yyyy`, Mac 은 `export ...`). 관리 탭에서 채널을 "텔레그램" 또는 "둘 다"로.
- ⚠️ 주제 이름을 아는 사람은 누구나 알림을 볼 수 있습니다 — 공유하지 마세요.

### 🟦 티커 누르면 토스증권으로
- 모든 화면의 종목 옆 **`토스↗`** 버튼(종목 상세에서는 **토스증권에서 열기 ↗**)을 누르면 토스증권의 해당 종목 페이지가 열립니다. 카드·격자의 나머지 부분을 누르면 기존처럼 이 앱의 상세 화면.
- 링크 방식(관리 탭): **앱 우선(없으면 웹, 권장)** `toss.onelink.me` · **앱 바로 열기** `supertoss://` · **웹** `tossinvest.com/stocks/<코드>/order`.
- 토스 종목코드(예: SOUN → `US20220428003`)는 토스 공개 웹 API로 찾아 `data/toss_codes.json` + DB 에 캐시합니다 (2,436개 미리 포함). 코드를 못 찾은 종목(유니버스 2,520 중 93개)은 **토스증권 홈**으로 연결됩니다.
- 솔직한 한계: 링크·종목코드는 검증했지만(HTTP 200), **실제 폰에서 토스 앱이 바로 열리는지는 테스트하지 못했습니다.** 안 되면 링크 방식을 바꿔 보세요.

## 2. (선택) PC 없이 쓰기 — GitHub Actions(알림) + Streamlit Community Cloud(대시보드)
저장소 **https://github.com/ogeunho011-dotcom/short-dashboard** (비공개, 이미 생성됨)에 이 폴더를 올리면:
- `.github/workflows/alerts.yml` — 월~금 미국 프리마켓~애프터(뉴욕 04:00~20:00, 서머타임 자동) 동안 정규장 20분·장외 60분 간격으로 스캔 → ntfy/텔레그램 알림. 기록은 `alert-data` 브랜치에.
- `.github/workflows/daily.yml` — 매일 한국 10:20 데이터 갱신 → DB 스냅샷을 릴리스 `db-latest` 에 업로드.
- Streamlit Cloud 대시보드는 그 스냅샷과 알림 기록을 15분마다 받아 표시 (관리 탭 설정·매매일지는 유지).

**따라하기 안내(한국어, 단계별): [`docs/CLOUD_SETUP.md`](docs/CLOUD_SETUP.md)** — 파일 올리기 → GitHub Secrets(`NTFY_TOPIC` 등) → Actions 실행 → 토큰 → share.streamlit.io 배포 → ntfy 구독·홈 화면 추가 → 한계(앱 12시간 잠자기, 예약 실행 지연·누락, 무료 월 2,000분 중 약 1,500분 사용 추정).
- 비밀값은 저장소에 절대 넣지 않습니다: GitHub → Settings → Secrets / Streamlit → App settings → Secrets 에만. 예시: `.streamlit/secrets.toml.example`. `.gitignore` 가 DB·pkl·알림기록·`secrets.toml`·`.env` 를 제외합니다.
- 비공개 저장소에서 배포한 Streamlit 앱은 비공개(로그인한 본인·초대한 사람만). `APP_PASSWORD` 를 Secrets 에 넣으면 비밀번호 화면이 한 겹 더 생깁니다.
- PC 방식(1번)도 그대로 동작합니다. 클라우드와 PC 알림 스캐너를 동시에 켜면 알림이 두 번 올 수 있으니 하나만 쓰세요.

PWA 메모: Streamlit 은 `<head>` 를 고칠 수 없어 실행 시 작은 스크립트로 앱 이름·아이콘·테마 색·manifest 를 넣습니다 (`static/`, `.streamlit/config.toml` 의 `enableStaticServing = true`). 브라우저에 따라 아이콘/전체 화면이 적용되지 않을 수 있고, 오프라인·푸시 알림은 없습니다.

### 기본 유니버스 (관리 탭에서 전부 수정 가능)
- 나스닥·NYSE·NYSE American 상장 **초소형~소형 보통주 전부**: 시가총액 **< $2B** (나노 <$50M · 초소형 <$300M · 소형 <$2B · 시총 미상 신규 상장 포함), 주가 **$0.05 이상**, 장외(OTC) 제외
- 제외: ETF/ETN·펀드(폐쇄형·BDC)·워런트·권리·유닛·우선주·채권형(노트·사채)·SPAC·테스트 종목 (Nasdaq Trader 종목 디렉터리 + 이름 규칙)
- 목록은 주 1회 다시 만들고(상장폐지·신규 상장 반영), 그 외 날은 가격·시총만 갱신
- 20일 평균 거래대금 **≥ $100K**, 최근 20일 중 거래량 0인 날 **≤ 3일** (죽은 종목 제외)
- 1차 가격 순위(거래량 배수·5일 거래량·갭 유지·20일 고가 돌파·거래량 연속 증가·과거 급등 이력) 상위 **200종목** 정밀 분석 → 유통주식 **> 50M주 제외**, '소형 유통' 기준 **< 20M주**
- 거래량 배수 = 당일 ÷ max(20일 중앙값, 20일 평균×0.5, 20,000주), 최대 50배 → 거래 없던 종목의 극단 배수(예: 이전 NEXR 2,956배) 제거
- 캐시: 일봉 일괄 6시간, 숏 잔고·공시 12시간, 재무 24시간 → 두 번째 스캔부터 약 1분 (첫 스캔은 수 분)

## 5. 모델 개요 (모두 추정)
- **진입 구간 맵**: 최근 90일 일별 숏 볼륨을 그날 고가~저가에 정규분포로 배분 → 이후 가격 경로에 따라 커버(기본 1%/일 + 밴드 상단 돌파 시 거래량 비례 커버) → 최신 공식 숏 잔고 총량에 맞춰 스케일. 연속 밴드를 차수(1차=가장 오래된)로 묶고 태그(신규/커버 소진/청산), 공백 구간 표시.
- **재점화 레벨**: 현재가 위 가장 가까운 차수의 상단 (돌파 시 손실권 숏 커버 압력 가정).
- **경보 점수 (급등 잠재력 점수)**: 아래 신호를 0~1.5로 정규화해 가중 평균 ×100 − 희석 패널티. 레벨 1~5 (25/40/55/70 경계). 경보 = 검증 모델 점수 상위 5% (research.json 없으면 이전 규칙: 점수 ≥ 27.9 그리고 동시 신호 3개 이상).
- **초보자용 한 줄 요약**: 홈 관심종목 카드, 스크리너 각 종목, 종목 화면 헤드라인 카드 아래에 쉬운 말 한 줄 (예: "공매도 물량 대부분 손해 중, $0.45 넘으면 급등 가능성 ↑ · 시장에 도는 주식 70만 주뿐이라 쉽게 크게 움직임"). 좋은 신호 최대 2개 + 주의 1개 (증자 서류, 갭 후 밀림, $1 미만 상장폐지 위험). 모두 추정이며 매수 신호가 아닙니다.

- 비교한 모델: 기존 가중 점수 / **게이트 가중(표본 ≥ 25건 & lift ≥ 1 인 신호만, 하한 근처는 절반 가중)** / 로지스틱 회귀(AUC 0.672) / GBM(0.651). 표본외 AUC·Brier 가 가장 좋은 게이트 가중을 채택.
