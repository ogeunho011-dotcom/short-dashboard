## 1. 💣 희석·상폐 구조 (참고 — 점수에 안 넣음)
`core/structure.py`, 검증 `scripts/structure_study.py` → `model/structure_study.json`.
그날까지 공개된 정보만 사용(미래 정보 없음). 7개 신호:
overhang(전환사채·워런트 물량), shgrow(주식수 급증), runway(현금 소진), near10($0.10 근처),
baby(초저가·소형), qwin(분기 실적 개선), prfade(최근 공시 후 하락).

검증(5구간):
- 넓은 기준(+30% 터치/5일, 125,807건, 기본 8.2%): 신호 3개 이상 9.9%(n=15,707), 5일 종가 중앙값 -2.7% (기본 -1.7%).
  → 크게 튀는 일은 조금 많지만 5일 뒤 종가는 더 나쁨.
- 앱 라벨(기본 36.8%): 모든 신호가 기본 이하, 3개 이상 30.4%.
- 결론: 점수 반영 안 함. 카드에 참고로만 표시. 전환사채 데이터는 XBRL 기준이라 과소추정.

## 3. 🌙 종가 베팅 (`?p=close`)
`core/closebet.py`, 검증 `scripts/closebet_study.py` → `model/closebet_study.json`.
매수 = 마감 직전(15:45 ET 근처), 매도 = 다음날 시가. 비용 0.5% 뺌.

과매도 지표: RSI(2), RSI(14), 5·20일선 이격, 20일 고점 대비 하락, 연속 하락일, 스토캐스틱.
체결강도(추정): 1분봉 틱 규칙(오른 틱 거래량/내린 틱 거래량×100, 100%=균형), 마감 60분과 정규장 전체.
실제 체결강도가 아닌 추정치.

### 결과 (일봉, 2024년~, 앞 60% 학습 / 뒤 40% 검증)
- 조건 없이 매수: 검증 평균 -0.44%, 갭 상승 42.5%.
- 학습 평균 1위 규칙(20일 하락 -30% + 일봉 강도≥100 + 거래량 3배): 검증 +0.18%, 실패.
- 구간 안정성 1위 규칙(20일 하락 -30% + 거래량 1.5배): 검증 -0.10%, 실패.
- 표시 규칙: **연속 하락 3일 이상 + 거래량 3배 이상** — 두 기준 모두 2위. 5구간 모두 플러스(+2.2/+0.1/+0.9/+1.3/+1.8%).
  학습 1,011건 +1.00%, 검증 894건 +1.59%, 이긴 비율 41%, 중앙값 -0.5%. 사후 선택이라 낙관적일 수 있음.
- 걷기 검증: 3구간까지로 고른 규칙 → 4구간 +1.09%(336건), 4구간까지로 고르면 이 규칙이 뽑힘 → 5구간 +1.78%(516건).
- 수익은 소수의 큰 갭 상승에서 나옴(중앙값 음수). 근거 약함.

### 분봉(5분봉 59일, 391종목, 18,643건)
- 마감 60분 체결강도(추정)≥150%: 다음날 시가가 15:45 가격보다 높을 확률 59.6% (기본 46.9%, <100%는 37.8%).
- 상관계수 0.067로 작음. 비용 0.5%에 비하면 효과 작음 → 추가 조건(참고, 검증 짧음).
- 표시 규칙 145건: 시가 매도 평균 +2.5%, 프리장 +3% 익절 방식 -1.5% → 시가 매도 유지.
