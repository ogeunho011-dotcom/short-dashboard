# 알림 개선 (2026-10-29) — 근거와 한계

## 바뀐 것
1. **장중 빠른 스캔** `alerts-loop.yml`: 한 작업이 프리마켓 04:00~정규장 16:00(뉴욕) 동안 약 150초마다 반복.
   6시간 한도 전(330분)에 다음 작업을 스스로 띄움. 중복 실행 방지(더 오래된 실행 중 작업이 있으면 종료). 30분마다 cron 이 살아있는지 확인·재시작.
   기존 `alerts.yml`(20분)은 백업 — 반복 작업이 돌면 건너뜀. 애프터마켓은 계속 `alerts.yml`.
   로컬 측정: 1회차 약 42~79초 (넓은 감시 986종목 1분봉 일괄 27~29초 포함).
2. **감시 범위**: 핵심(관심 + '가능'·경보 전부 + '대기' 점수순) 매번 전체 계산 + 넓은 감시(마지막 스캔 전 종목 + 거래대금 $10만↑ 유니버스, 약 1,000종목)를
   1분봉 일괄로 훑어 +10% 이상(또는 5분 +8%·프리 갭) 움직인 종목만 최대 25개 전체 계산.
   10/28 정규장 상승 상위 20 중 예전 대상(25종목)에 있던 것 3개 → 넓은 감시 17개 (멤버십은 현재 DB 기준이라 근사치).
3. **급등 알림 조건**
   - 정규장: 현재가가 VWAP 보다 10% 넘게 위면 안 울림. 60일 5분봉(1,600종목, 2026-08-20~10-28, 첫 신호) 백테스트:
     VWAP +10% 이하 승률(+10% 먼저 도달 vs −8%) 40.4%·n=1,290 / 초과 27.5%·n=389. 앞·뒤 기간 나눠도 같은 방향.
   - 고점 대비 되밀림 조건은 기간별로 결과가 엇갈려 **넣지 않음**.
   - 애프터마켓에는 급등·거래량·재점화(장중형) 알림 안 보냄 (설정 post_intraday).
   - 거래량 급증: 전일 대비 +5% 이상일 때만 (백테스트: 0~5% 구간 +10% 도달 2%뿐), 최근 5분 거래대금 $2만 이상 (체결 가능성 — 적중률 근거 아님).
   - 종목당 쿨다운 하나(종류 무관 120분) + 하루 최대 3번.
   - 내부자 매수 호재 기준 $1만 → $10만 (근거: 10/28 OWLS $2.2만 사례 — 백테스트 아님).
4. **공시**: EDGAR 최신 공시 피드(8-K·6-K·Form 4·SC TO-T, 최근 3시간)로 넓은 감시 전체 확인 + 8회에 1번 기존 전체 확인. SEC 초당 8회 이하.
5. **버그**: 등락률 기준 종가를 일봉 DB 로 교차 확인 (AEYE 10/28 04:07 ET +40% 오표시 → 실제 +1%), 손절이 음수·0이거나 −50% 넘으면 보정, 목표 +200% 초과 보정.
6. **스크리너 1차 선별은 그대로**: 일봉 백테스트에서 거래대금 구간별 10일 내 +20% 도달률이 23.5~24.7%로 차이 없음 → 완화 근거 없음.
